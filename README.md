# Delphi PAT Ideas

This repository contains various Delphi projects and ideas related to different functionalities and UI components.

## Projects:
1. **Password Visible**  
   Toggle the visibility of a password input field.

2. **Sending Email**  
   A Delphi application to send emails programmatically.

3. **South Africa Map**  
   Display and interact with a map of South Africa.

4. **Change Cursor**  
   Change the cursor type based on user interaction.

5. **Check If Connected To Internet**  
   Check if the system is connected to the internet.

6. **Move An Image With Click**  
   Move an image around the screen by clicking and dragging.

7. **Login Screen**  
   A simple login screen for authentication.

8. **Interactive Loading Screen**  
   A loading screen with interactive elements while the application is processing.

## Usage:
These ideas were implemented in Delphi and demonstrate various techniques such as handling mouse events, sending emails, and managing user interfaces.
